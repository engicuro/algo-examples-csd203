10_recursion_binary_search.py - Mechanism Explanation

Data Structures Used:
- A sorted tuple of integers (immutable sequence).
- Integer indices (low, high, mid) to track the current search range.

Algorithm Overview:
Binary search is a divide-and-conquer algorithm that efficiently locates a target value within a sorted collection by repeatedly halving the search space.

Step-by-Step Mechanism:
1. The function receives a sorted tuple, a target value, and a search range defined by low and high indices.
2. Base Case 1 (Empty Range): If low > high, the search range is empty, meaning the target is not present. Return -1.
3. Compute the middle index: mid = (low + high) // 2.
4. Base Case 2 (Found): If sorted_list[mid] == target, the target is found at index mid. Return mid.
5. Recursive Case - Search Left Half: If target < sorted_list[mid], the target must be in the left half. Recursively call binary_search(sorted_list, target, low, mid - 1).
6. Recursive Case - Search Right Half: If target > sorted_list[mid], the target must be in the right half. Recursively call binary_search(sorted_list, target, mid + 1, high).
7. Each recursive call narrows the search range by roughly half, eliminating one half of the remaining elements.

Key Operations:
- Index arithmetic to compute the midpoint.
- Comparison between the target and the middle element to decide which half to search.
- Recursive calls that pass updated low/high bounds.

Time Complexity:
- O(log n) in the worst case, where n is the number of elements. Each step halves the search space.
- O(1) in the best case (target is at the middle of the initial range).

Space Complexity:
- O(log n) due to the recursive call stack depth (log n recursive calls in the worst case).
