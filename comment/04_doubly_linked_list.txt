04_doubly_linked_list.py — Doubly Linked List
==============================================

Data Structures Used:
- Node class: Each node stores a value, a next pointer (to the next node), and a prev
  pointer (to the previous node). This bidirectional linking allows traversal in both
  directions.
- DoublyLinkedList class: Maintains both a head pointer (first node) and a tail pointer
  (last node), enabling efficient operations at both ends.

How the Algorithm Works (Step by Step):

1. Node Creation: Each Node has three fields — value (data), next (pointer to successor),
   and prev (pointer to predecessor). The first node has prev=None; the last node has next=None.

2. insert_at_head(value):
   - Create a new Node.
   - If the list is empty, set both head and tail to the new node.
   - Otherwise:
     a. Set new_node.next = self.head (new node points to old head).
     b. Set self.head.prev = new_node (old head points back to new node).
     c. Update self.head = new_node (new node becomes the first node).
   - Time: O(1) — no traversal needed thanks to the head pointer.

3. insert_at_tail(value):
   - Create a new Node.
   - If the list is empty, set both head and tail to the new node.
   - Otherwise:
     a. Set self.tail.next = new_node (old tail points to new node).
     b. Set new_node.prev = self.tail (new node points back to old tail).
     c. Update self.tail = new_node (new node becomes the last node).
   - Time: O(1) — no traversal needed thanks to the tail pointer.

4. delete_by_value(value):
   - If the list is empty, print a message and return.
   - Walk through the list from head to tail looking for the node with the matching value.
   - Four cases are handled when the node is found:
     a. Only node in the list: set both head and tail to None.
     b. Deleting the head: move head to head.next and set new head's prev to None.
     c. Deleting the tail: move tail to tail.prev and set new tail's next to None.
     d. Deleting a middle node: set current.prev.next = current.next and
        current.next.prev = current.prev, bypassing the deleted node.
   - Time: O(n) — worst case requires traversing the entire list to find the node.

5. traverse_forward():
   - Start at head, follow next pointers, and build a string with " <-> " between values.
   - Append " -> None" at the end.
   - Time: O(n).

6. traverse_backward():
   - Start at tail, follow prev pointers, and build a string with " <-> " between values.
   - Prepend "None <- " at the beginning.
   - Time: O(n).

Key Operations Summary:
- Insert at head: O(1)
- Insert at tail: O(1)
- Delete by value: O(n)
- Traverse forward: O(n)
- Traverse backward: O(n)

Time Complexity: O(1) for insertions at head/tail; O(n) for deletion and search
Space Complexity: O(n) for storing n nodes; each node uses extra space for the prev pointer;
O(1) auxiliary space for pointer manipulation

Key Advantage over Singly Linked List:
Bidirectional traversal is possible because each node has both a next and prev pointer.
This allows O(1) deletion of a node when you have a reference to it (no need to find
the previous node by scanning from the head), and efficient operations at both ends.
